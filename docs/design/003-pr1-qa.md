## 三轮验收的关键发现

1. **首轮打回**：0 行空状态不可达（外层按 columns 判断，MySQL 0 行仍返回列名 → 空状态成为死代码）
2. **次轮打回**：修复 clickoutside 时引入严重回归——筛选面板打开且有草稿时，右键快捷筛选会先触发 clickoutside 关闭面板，导致草稿被 Applied 覆盖丢失（teleport 菜单左键同样触发）
3. **终轮通过**：clickoutside 忽略右键/快捷菜单/下拉菜单；打开菜单时快照草稿作为追加基底；真实鼠标事件复测三条路径均保留草稿
